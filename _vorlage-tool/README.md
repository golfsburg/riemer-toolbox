## Neues Tool aus dieser Vorlage anlegen
1. Ordner `_vorlage-tool` kopieren und umbenennen (Kleinbuchstaben, Bindestriche, z. B. `rohr-rechner`).
2. Gewünschte Lizenz aus `../LICENSES/` als `LICENSE` in den Ordner kopieren.
3. `SPDX-License-Identifier` und `<meta name="license">` in `index.html` anpassen
   (`MIT`, `CC-BY-NC-4.0` oder `LicenseRef-Proprietary`).
4. Tool in der Tabelle der Haupt-`README.md` und in der Startseite `index.html` eintragen.
