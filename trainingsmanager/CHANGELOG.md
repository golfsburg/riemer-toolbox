# CHANGELOG – Trainingsmanager (RIEMER Tools)

Neueste Version oben.

## V3.5.2 · 27.11.2026 · DEV
**Neu**
- **Bereichsfarben (Regel S-28, Rollout R-24):** Boxen zeigen ihre Funktion mit einer von vier Farben. Zone a (Blau): Übersichtskarten · Zone b (Laubgrün): Bedienleisten, Eingabe und Taktiktafel-Formulare · Zone c (Bernstein): Übungsbeschreibung · Zone d (Violett): Einstellungen/Optionen. Höchstens drei Zonen je Ansicht, kein Rot.

**Geändert**
- **Dialoge per Tastatur (Regel S-25, Rollout R-21):** In „Neu“ und „Speicher“ gilt Enter = Hauptknopf (Verbinden bzw. Schließen) und Esc = Schließen; ein zentraler Handler ersetzt die eigenen Esc-Handler.
- **Menüband kompakt (Regel S-26, Rollout R-22):** einzeilig (≈45 px) ohne Bildlaufleiste, Verlaufskante bei Platzmangel, Gruppennamen als Tooltip, sichtbarer Fokusrahmen.
- Offenes Overlay sperrt das Scrollen der Seite (S-18).
- Theme aus `riemer-theme` (hell/dunkel) wird beim Start übernommen.

## V3.5.1 · 25.11.2026 · DEV
**Geändert**
- **Tool-Typ „Datenbank“ (Regel S-23, Rollout R-19):** Das Tool ist als Typ Datenbank gekennzeichnet – Daten bleiben wie bisher im Tool, keine Projektdateien.
