# Trainingsmanager

Fußball-Trainingsübungen, Taktiktafel und Bewegungsübungen als Animation – für Nachwuchs-Trainer (RIEMER Tools).

**Online:** https://tools.riemer.co/trainingsmanager/
**Lizenz:** `LicenseRef-Proprietary` – siehe [LICENSE](LICENSE)

> 🔒 Geschütztes Tool: `index.html` ist nur die Schlüssel-Abfrage. Der eigentliche Code wird nach
> erfolgreicher Lizenzprüfung vom Server geladen – siehe [`../lizenz/LIZENZVERWALTUNG.md`](../lizenz/LIZENZVERWALTUNG.md).
> Tool-ID in der Lizenzverwaltung: `trainingsmanager`

## Funktionen
- Animierte Übungen: Passspiel, Dribbling (inkl. Richtungswechsel auf Signal mit Ton), Torschuss, Spielformen
- Bewegung: Hüftmobilisation in Rückenlage als 3D-Figur, Ansicht drehbar
- Taktiktafel: Spielzüge zeichnen, abspielen, importieren und duplizieren
- Mannschaften mit Kader (Foto, Nummer, Kurzname) zum Aufstellen
- Einheitliche Anzeige-Optionen, Tempo, Schritt-für-Schritt-Steuerung, Hell-/Dunkelmodus

Eigene Spielzüge und Kader werden lokal im Browser gespeichert (optional gemeinsam über ein GitHub-Repository, ☁-Knopf).
