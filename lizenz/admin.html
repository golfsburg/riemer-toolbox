Versionen

Jede Lizenz bekommt die neueste aktive Version aus ihrem Kanal und ihrer Edition (Dev sieht Dev + Beta + Stabil, Beta sieht Beta + Stabil; fehlt eine Edition, gilt Standard). Kanal und Edition lassen sich direkt in der Tabelle umstellen. „Freigeben“ verschiebt eine Version in den nächsten Kanal, „Zurückziehen“ nimmt sie aus der Auslieferung – dann gilt automatisch wieder die vorige.

Editionen

Editionen sind parallele Ausprägungen eines Tools (z. B. Light, Pro) – unabhängig vom Kanal. „Standard“ gibt es immer. Jede Version wird für eine Edition hochgeladen; im Tool steht die Edition als window.RITL.edition zur Verfügung.
