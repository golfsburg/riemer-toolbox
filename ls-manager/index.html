Anleitung
  1. Archivordner wählen – einmalig; danach wird er bei jedem Start eingelesen (Chrome/Edge).
  2. Lieferscheine ablegen – PDF, Foto oder Scan in das Feld ziehen. Die Daten werden automatisch erkannt.
  3. Prüfen – automatisch gefüllte Felder sind blau hinterlegt. Korrekturen bleiben erhalten.
  4. Archivieren – speichert unter Archivordner / Lieferant / Datum_Nummer.pdf samt Datensatz.
  5. Archiv durchsuchen – links nach Monaten gruppiert, mit Suche, Summe und Export als CSV.

Unter Einstellungen trägst du deine eigene Firma ein, damit sie nie als Lieferant übernommen wird. Backup sichert alle erfassten Daten als JSON.
Einstellungen

Ein Begriff pro Zeile (Firmenname, Straße, Ort). Diese Angaben stehen auf jedem Lieferschein als Empfänger und werden deshalb nie als Lieferant übernommen. Gespeichert nur in diesem Browser.
