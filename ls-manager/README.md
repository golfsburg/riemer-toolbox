# Lieferschein-Manager (Demo)

Lieferscheine automatisch auslesen und je Lieferant im eigenen Archivordner ablegen (RIEMER Tools).

**Online:** https://tools.riemer.co/ls-manager/
**Lizenz:** Demoversion, frei testbar ohne Lizenzschlüssel – siehe [LICENSE](LICENSE)

## Funktionen
- PDF, JPG, PNG, TXT per Drag & Drop; PDF-Text wird spaltengetreu gelesen, Scans/Fotos per OCR (Deutsch)
- Lieferant, Lieferscheinnummer, Lieferdatum, Bestellnummer, Gesamtbetrag und Kategorie werden automatisch vorausgefüllt
- Ablage: `Archivordner / Lieferant / JJJJ-MM-TT_Lieferscheinnummer.pdf` + `.json` mit den Daten
- Archiv wird beim Start eingelesen und nach Monaten gruppiert (Anzahl, Summe, Suche)
- Warnung bei doppelten Lieferscheinen, Export als CSV und JSON, Hell-/Dunkelmodus
- „Beispiel-Lieferschein laden“ zum Ausprobieren ohne eigene Dateien

Direktes Speichern in Ordner: Chrome oder Edge. Alles läuft lokal im Browser.
