# PDF.ritl

PDF-Dokumente zusammenstellen – RIEMER Tools `#ritl_pdf`, abgeleitet von DECK.ritl aus [PPTX.ritl](../pptx.ritl/).

**Online:** https://golfsburg.github.io/riemer-toolbox/pdf.ritl/
**Lizenz:** `LicenseRef-Proprietary` – siehe [LICENSE](LICENSE)

> 🔒 Geschütztes Tool: `index.html` ist nur die Schlüssel-Abfrage (Tool-ID `pdf-ritl`). Der eigentliche Code wird nach
> erfolgreicher Lizenzprüfung vom Server geladen – siehe [`../lizenz/LIZENZVERWALTUNG.md`](../lizenz/LIZENZVERWALTUNG.md).

## Funktionen
- Mehrere `.pdf` laden – per Drag & Drop, aus verbundenen (SharePoint-)Ordnern oder zuletzt verwendet
- Abschnitte automatisch aus den **Lesezeichen** (Ebene wählbar) und zusätzlich **eigene Trennstellen** (✂ teilen, ⤒ zusammenführen, ✎ umbenennen) – auch bei PDFs ohne Lesezeichen
- Ganze Abschnitte oder einzelne Seiten auswählen, Großansicht mit Blättern, Matrix-Ansicht über alle Dateien
- Storyboard per Drag & Drop ordnen, Titel umbenennen
- Deckblatt aus beliebiger Seite; verlinktes Inhaltsverzeichnis (schlicht oder auf einer Vorlagenseite)
- Lesezeichen je Abschnitt inkl. untergeordneter Lesezeichen der Quellen, „◀ Inhalt“-Knopf, fortlaufende Seitenzahlen
- Seiten werden verlustfrei kopiert; interne Links bleiben erhalten, Formulare werden fixiert, geschützte PDFs als Bild übernommen
- Favoriten pro Lizenz, Backup & Restore als `.json` oder `.zip` inkl. PDF-Originale – auch direkt in einen gewählten Ordner

Alle Daten werden lokal im Browser verarbeitet – nichts wird hochgeladen.
