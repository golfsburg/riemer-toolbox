# PPTX Manager

Präsentationen aus PowerPoint-Abschnitten zusammenstellen (RIEMER Tools).

**Online:** https://tools.riemer.co/pptx-manager/
**Lizenz:** `LicenseRef-Proprietary` – siehe [LICENSE](LICENSE)

> 🔒 Geschütztes Tool: `index.html` ist nur die Schlüssel-Abfrage. Der eigentliche Code wird nach
> erfolgreicher Lizenzprüfung vom Server geladen – siehe [`../lizenz/LIZENZVERWALTUNG.md`](../lizenz/LIZENZVERWALTUNG.md).

## Funktionen
- Mehrere `.pptx` laden – Abschnitte werden automatisch erkannt (Datei- und Matrix-Ansicht)
- Ganze Abschnitte oder einzelne Folien auswählen, Vorschau mit Blättern
- Storyboard per Drag & Drop ordnen, Titel umbenennen
- Startfolie aus beliebiger Präsentation als Design-Referenz, Texte direkt anpassbar
- Automatisches, verlinktes Inhaltsverzeichnis + saubere PowerPoint-Abschnitte
- Optionaler „← Inhalt“-Knopf auf jeder Folie, „RIEMER Tools“-Kennzeichnung auf Deckblatt & Master
- Backup & Restore: Auswahl als `.json`, Komplett-Backup inkl. PPTX als `.zip`

Alle Daten werden lokal im Browser verarbeitet – nichts wird hochgeladen.

## Nutzung
1. `index.html` im Browser öffnen – oder online aufrufen.
