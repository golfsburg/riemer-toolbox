# JFC.ritl

Engineering Navigator – Kundenvergleich, Besuchspriorisierung und Gebiets-Review aus JFC-Reports · RIEMER Tools `#ritl_jfc`.

**Online:** https://golfsburg.github.io/riemer-toolbox/jfc.ritl/
**Lizenz:** `LicenseRef-Proprietary` – siehe [LICENSE](LICENSE)

> 🔒 Geschütztes Tool: `index.html` ist nur die Schlüssel-Abfrage (Tool-ID `jfc-ritl`). Der eigentliche Code wird nach
> erfolgreicher Lizenzprüfung vom Server geladen – siehe [`../lizenz/LIZENZVERWALTUNG.md`](../lizenz/LIZENZVERWALTUNG.md).

## Bereiche
KPI-Kacheln mit Trend · Cross-Filter & Drill-down (Top 15 / Flop 10, Befestigungspartner, Heatmap, Besuchspriorität) · Power-Tabelle ·
Analysen (Pareto, VON gegen BIS, Score-Treiber) · Kunden-Steckbrief, Besuchsplan, Pipeline, VB-Report, Produktmix · Gebiets-Review · Export & Teilen.

**Daten & Setup:** JFC-Reports (XLSX) importieren, Import-Mapping, Besuchsscore, Tool-Export (Kundenversion als eigenständiges, schreibgeschütztes HTML-Tool).
**Exporte:** XLSX, PowerPoint mit Export-Sets, CSV, PNG, PDF – jede Darstellung nennt Zeitraum und Referenz.

Änderungen je Version: [CHANGELOG](CHANGELOG.md)

Alle Daten bleiben lokal im Browser; Backup als `Backup_JFC-ritl.json` (ritl-bk), optional im OneDrive-/SharePoint-Ordner.
